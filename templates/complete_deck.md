# 完整演示模板

按内容决定章节与页数。用户给定的页数包括封皮、章节和封底时，把这些页面纳入总页数。已经定稿的页数或章节不要自行扩展。

- 封皮用生成的主题主场景和透明艺术字组合出一个视觉中心。
- 章节页用统一格式的编号与标题开启新段落，每章有对应场景。
- 内容页先确定图文关系再定构图。试排主题标题字体和容易阅读的正文字体，标题与正文使用不同字族。可采用按时间、主题、问题推进、图文对照或结论与依据等组织方式。依据用户提供的版式图选择图位，正文可拆成直观的解释区。
- 封底用主题结束画面承接最后一页内容，收尾文字用原生文本。

用 `scripts/deck.py build plan.json outputs/deck.pptx` 从组版清单生成可编辑 PPTX，或用可直接编辑的工具制作。渲染后制作缩略总览。校样 PPTX 按需要生成。具体布局和检查见 [版式](../references/layout.md) 和 [复现](../references/verification.md)。
