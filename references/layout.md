# 内容页版式选择

版式来自用户给过的内容页、双图排版、折页和多图示例。使用这些参考时提取图位、主次、读图方向和图文配对，把原示例的商务配色、人物与标题换成当前主题的水粉画面和内容。

## 先判断这页要读什么

1. **数信息图位。** 数出观众需要逐一看的照片、地图、图表或组合图。背景水粉、胶带和贴纸属于装饰。同一证据的原图、放大窗和说明可以作为一个图组。两地点各含光学与雷达图时，按两组等权对照来排，并让组内两图靠在一起。
2. **判断图的关系。** 依次看有没有时间或步骤，能不能同尺度比较，是否有一张主图，是否共享一个中心，是否需要逐项横向对照。关系决定排列方式。日期需要有方向，等权比较需要同权重，主次证据需要不同尺度。
3. **核算内容容量。** 先找出图里必须看清的标尺、坐标和标签，再给正文配行宽。保留长图的横幅空间，窄图可用竖位或拼接成组。可放大关键部位，按原比例调整图框或裁切。对同一地点和尺度的证据，保持可比的取景、方向与显示大小。
4. **匹配用户参考。** 识别参考里的图数、图位大小、正文位置、阅读顺序和可裁切范围。用一句短注记录选择理由，例如「本站两种影像成对，按两行对应」。确认参考的装饰形状和示意文字留出相同的图文空间，再换成当前主题资产。

## 图文关系与适用版式

| 内容条件 | 参考构图 | 怎么放图和文字 |
| --- | --- | --- |
| **一张主图，文字较多** | 一侧主图加两三段说明、局部叠纸 | 图为重点时给约 55–70% 内容宽度。文字为重点时给正文足够行宽，辅图放一侧。解释按图中部位或讲述顺序排列 |
| **一张图，有 3–5 个并列观察点** | 中心圆图配周边注释、底部半圆配扇形展开 | 中心放场景、地图或物体，说明按点位分在两侧或外圈。文字较长时用侧栏排开，短引线只指向相关部位 |
| **一张图，配多段时间或条目** | 大图加弧形节点，右侧说明排成一列 | 固定图在一边，日期和条目在另一边等序展开。弧线只串联真正有顺序的节点，横向对齐便于查找 |
| **两张等权图，需要直接对照** | 双联相纸、双窗、两列图区加图注 | 同宽同高，图注沿相同基线放在图下或图旁。保留同一观察尺度。地图或图表需要等比保留，版面形状放在外框上 |
| **两张图分主次，或一张是局部** | 大小错位相纸、纸层叠放 | 主图完整且更大，小图与主图的对应部位靠近，可配细引线或放大框。只在相纸边角做叠放，给关键读图区域留空间 |
| **两张图各自对应一段解释** | 上下交错图文、两栏色块与图片交替、斜边或圆角双幅 | 先定每组图文关系，再把上下两组镜像或错位。适合两方面各讲各的。装饰性照片可裁成弧形，图表、原始影像和地图用完整图框 |
| **三张图有阶段或日期** | 三折页、连幅相纸、阶梯、沿路线的时间轴 | 按日期或步骤排开，短标签贴近图位。阶段同等重要时尽量等宽。只有内容有推进、递进或排序时采用阶梯关系 |
| **三张图有一主两辅** | 中间大图、两翼小图，或一张大图带两张近景 | 主图可占图组宽度的约 45–60%，左右小图说明局部或补充条件。图注在各自图位下，按先主后辅引导视线 |
| **三至四张图各自独立，可并列比较** | 等宽竖卡、多行图文表格、折屏 | 每项有对应图片和短说明，遵循同一阅读顺序。需要逐列对条件或指标时用行列对齐。斜切、上下错位可用于装饰性外框，让标题和图内信息保持水平 |
| **四至六张图共享一个过程** | 横向胶片、分段长条、弧形路线、环形节点 | 关联图靠近，流程按同一方向标号或写日期。每张图的注释贴着对应节点。循环用闭环，无循环的过程留清楚的起点和终点 |
| **多张小图是同一组证据** | 拼接面板、展板拼贴、主图 + 两三列小图 | 按地点、传感器、时间或证据类别拼组。缩小组内距离，把空间给最有信息量的小图。组内同尺度时统一图位和图注，让小图放在一起能看出它们的关系 |
| **多图围绕同一主题，关系较松** | 中心主题配两侧错落图片、大小不一的图片墙 | 中心简洁，两侧按语义分组。图位错落但图注与所属图片贴近。需要逐一精读的数据图优先用对齐的图组 |
| **地图、曲线和多个发现同页** | 一张主图加辅助图组，结论放在对应图区附近 | 主图保证读数空间；地图可配局部窗，辅助图齐整成组。几个指标分别有可见边界和短说明，按需要在各自区域居中对齐 |
| **图少、正文或结论较多** | 两三个错位纸块、图标加短文、一个小景配较大文字区 | 先保证解释完整，再挑一张真正辅助理解的图。用纸边、颜色深浅和留白划出段落，能相关联的文字和贴图靠近 |

## 参考图中反复出现的规律

- **先确定主次，再做形状。** 参考图常用大图配几张小图、中心大图配两翼、两幅图围绕一个中心。中心位只放这一页最重要的图、关键关系或主题。
- **形状表达关系。** 双联和行列表格便于直接比较，折屏和连幅便于阅读顺序，环形适合循环或中心向外，错位相纸适合主辅和拼贴。斜面、弧边和切角可用来收边，信息关系优先靠位置和对齐读清楚。
- **同类重复建立秩序。** 并排照片或短说明可以同宽、同基线；有主次才变大小、有节奏才错高低。作为试排起点，可让组间距约为组内距的 1.5 倍，随后按实际图注和内容密度调整。
- **长说明使用完整的文字区域。** 短注可直接挨着图，较长的解释可用整块侧栏或交错图文区。版式示意里的占位文本条只代表容量。正文的内容、断句和标题形式按实际需要决定。

## 按主题选字体

1. 先看主题气质、插画笔触和标题长度，再列出本机能实际渲染的候选字体。自然观察或童趣主题可试圆体，手记或传统题材可试楷体，安静的出版物风格可试宋体。幼圆、楷体和思源宋体都是候选，实际使用按主题和本机可用字体决定。
2. 为章节与内容页选定标题字族，再配一个字形容易辨认的正文字族。正文可使用电脑已有的微软雅黑、等线或其他合适的系统字体。引语、图注和数据标记按可读性沿用正文，少量字重变化即可。封皮主标题可用独立图片艺术字。
3. 用最长的内容页标题、章节标题和一段中英数字混排的正文试排。确认字体覆盖中文、英文、数字、标点及必要符号，选定后在全套同级位置使用同一字族。若渲染时出现替代或出框，调整字体组合、字重、断句或文本框，并复核实际页面。

## 应用到水粉内容页

- 用主题主色、辅色、中性色、少量强调色和正文墨色统一全套。水粉纸纹是底层，柔边色晕、衬纸、弧边或错位纸片是中层，证据和文字在最前。分隔主要靠图组距离、纸边轮廓和颜色，纸边与色晕可以圆润收口或渐隐。
- 每页先有一个视觉中心，再安排辅助重心。贴纸按大小、高低和角度错落，靠相纸边、胶带或与内容有关的位置。背景形状和贴纸错开，给主图、边框和图中标签留出可读空间。
- 在 16:9 下以约 3–5% 的安全边起步。13.33 × 7.5 英寸画布可从 28–44 pt 标题、15–22 pt 正文、11–14 pt 图注试排。对地图、图例和多图标签用放映大小检验。若重要内容出框或太小，优先调整文字宽度、图位和分组。
- 连续页可以共用纸纹、字形和图注风格。随着内容关系变化切换图组结构和视觉重心。连续页若共同比较同一个条件，保持相同的尺度和位置有利于阅读。

## 三个套用示例

| 页面的逻辑 | 版式选择 |
| --- | --- |
| 两处地点都要比较光学影像与雷达图 | 用两行双幅矩阵。行是地点，列是影像类型，在对应图旁写日期或差异 |
| 三个日期显示亮斑的位置变化，另有完整原图 | 三张日期图并排，统一取景。完整原图作侧边小索引，底部留一块说明给参照点和坐标记录 |
| 一张距离曲线承担结论，右侧还有地图和补图 | 曲线占主图区，地图与补图拼成辅助组。数字发现各自放在下方短说明块，保留和图表的对应关系 |

最后按放映尺寸逐页确认。第一眼看到的元素符合本页重点，短注归属清楚，重要原图的裁切、位置、标签及图例符合用户要求，正文和装饰彼此留有余量。
